Visualizer Linked List C++

Eksplorasi interaktif memori pointer dan traversal node berdasarkan kode C++

Kecepatan:
main.cpp
C++ Standard
#include <iostream>
using namespace std;
 
struct Node {
    int data;
    Node* next;
};
 
int main() {
    // 1. Buat 3 node kosong
    Node* head = new Node();
    Node* second = new Node();
    Node* third = new Node();
 
    // 2. Isi data & sambungkan
    head->data = 10;
    head->next = second;
    second->data = 20;
    second->next = third;
    third->data = 30;
    third->next = NULL;
 
    // 3. Cetak isi linked list
    Node* temp = head;
    while (temp != NULL) {
        cout << temp->data << " -> ";
        temp = temp->next;
    }
    cout << "NULL" << endl;
    return 0;
}

Penjelasan Langkah

Klik tombol "Mulai" atau "Next" untuk menjalankan visualisasi baris per baris dari kode C++ linked list.
